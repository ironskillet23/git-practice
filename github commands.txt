github commands to put in Terminal
1. git init(enter)
2. git remote add origin https://github.com/ironskillet23/git-practice.git(enter)  Note: put unique url of respository you are adding
3. git add .(enter)
4. git commit -m "this is first commit"(enter)
5. git push -u origin master(enter)

note: ctrl c brings new command line up
To update github
1. git add . (enter)
2. git commit -m "any message" (enter)
3. git push (enter)

To pull from github
git pull origin master (enter)

To link to another repository
ctrl shift P (opens command window at top of screen)
Git: Clone
Ctrl V (paste url of repository)
